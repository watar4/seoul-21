# SEOUL 21

日本語のブラックジャック練習アプリ。静的HTML / CSS / JavaScriptのみで動作します。

- 画面の高さに収まるカードテーブル（スマホ375×600・390×700で確認）
- 横スクロールできる立体チップ一覧。タップで加算、取り消し・クリア・金額入力に対応
- 開始チップ・モード・ルール・リセット・成績を設定ボタンに集約
- 勝敗表示 → ハンドごとのチップ精算 → 「振り返りを見る」または「次のベットへ」。レビューは自動で開かない
- ハンドシグナルモード（デフォルトON）。透過のリアルな手の8ポーズを使用し、指の曲がり・手首の動き・接地影を独立してアニメーション。アクション直後に表示、自動的に消去
- シューから弧を描く配札、立体反転・光沢、同じカードを維持したスプリット移動、ディーラーの追加配札・勝敗表示・チップ回収と配当を順に演出。演出中の追加操作を防止
- 演出速度は設定から「ゆっくり（標準）」「じっくり」「テンポよく」を選択・保存。標準では配札1秒、カード反転0.8秒（ディーラーの裏札1.3秒）、手の動作2秒。シグナルが終わってから配札を開始し、勝敗は約4.2秒見せてから精算する
- 行動確定の表示と手札確定は短くまとめ、シグナル後の間は0.12秒、ディーラーへ移る間は0.4秒。配札と勝敗を読む時間を保ちながら、操作後の待ち時間を抑える
- レビューに手札分類・推奨理由・覚えるパターン・選択制約の説明を表示。判断時点のルールも保存
- いつでも開けるベーシックストラテジー表（S17 / H17 / ENHC対応）
- ラウンド終了後、各判断時のカードと推奨行動をレビュー（オン・オフ可）
- 開始チップの編集は最初のプレイ前または残高ゼロ時のみ
- リセットは開始額を維持し、ラウンド・成績を初期化
- 残高、途中のラウンド、設定をlocalStorageに保存
- ヒット・スタンド・ダブル・最大3ハンドへのスプリット・サレンダー

## 起動 / テスト

Node.js 22以上で `npm start` → http://127.0.0.1:4173

`npm test` でゲームエンジン・レビュー・演出の進行順と精算金額のテストを実行。外部依存なし。

`http://127.0.0.1:4173/tests/animation-check.html` は開発用の手動確認ページ。ローカルの練習データを初期化し、勝利・敗北・引き分け・BJ・ダブル・スプリット・ヒット・サレンダー・ENHCを決められたカードで確認できます。

演出用の中間状態は保存せず、エンジンの確定状態を先に保存します。途中でリロードしてもチップを二重精算しません。OSの「視差効果を減らす」設定では移動や反転を抑えつつ、シグナルの説明や結果を読む時間は確保します。

手の素材: `assets/hand-signals.png`（組み込みimage_genで生成、透過PNG）。生成指示は `assets/hand-signals-prompt.md`。

## 練習条件

パラダイスシティ公式ゲーム案内のBJ配当3:2、最大3ハンド、DAS、スプリットAへの1枚追加を参考にしています。6デッキとS17は練習用の初期仮定です。公式案内の配札手順は曖昧なため、既定はディーラーBJ先確認・レイトサレンダーです。現地仕様の完全再現ではありません。別条件としてENHC（後から2枚目を配り、ディーラーBJなら追加ベットも失う、サレンダーなし）を選択できます。サイドベット・保険・イーブンマネー・ダブルフォーレスは省略しています。端数は0.01チップ単位で丸めます。ルールはラウンド間で変更できます。

参照: https://www.p-city.com/front/casino/gameGuide?language=JA

戦略の参照: https://wizardofodds.com/games/blackjack/strategy/4-decks/

推奨はハンド合計に基づくマルチデッキ・ベーシックストラテジーです。カードカウンティングや全カードの構成別例外は扱いません。レビューは残高不足、3枚以上の手札、分割上限を考慮します。勝敗と一致率は別の指標です。
